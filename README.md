# Atividade - Madeira e Cia Ltda.

## Descrição
Formulário web para cálculo de descontos conforme forma de pagamento.

## Descontos
- Depósito: 10%
- Boleto: 8%
- Cartão de crédito: sem desconto

## Arquivos
- index.html: formulário personalizado
- processa.php: lógica de cálculo

## Como testar
1. Abra index.html no navegador
2. Preencha os dados
3. O PHP precisa de servidor local (XAMPP) para funcionar

## Prints
- print1.png: formulário preenchido
- print2.png: resultado do cálculo
